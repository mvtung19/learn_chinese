# Implementation Prompt — Task 2: Layout & Trang chủ

## 1. Phạm vi
- Viết `index.html` cấu trúc ngữ nghĩa HTML5, thẻ meta viewport, font Google `Noto Serif SC` và `Outfit`.
- Viết `css/style.css` định nghĩa toàn bộ biến CSS token (colors, typography, transitions, elevation, light/dark mode).
- Tạo component Header (Toggle Hán Việt, Toggle Theme, Status badge).
- Tạo component Number Grid (5 con số).

## 2. Quy tắc bắt buộc
- Tuân thủ quy tắc D7: Không được dùng kiểu mobile scale-down hay desktop stretched. Mobile có navigation/card pad hợp lý; Desktop có multi-column rộng mở.
- Tự động lưu lựa chọn Hán Việt và Dark mode vào `localStorage`.

## 3. Xác minh
- Mở trên trình duyệt, test chuyển Dark/Light mode và toggle Hán Việt.
- Không chuyển sang task tiếp theo sau khi hoàn thành.
